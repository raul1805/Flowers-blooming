# 🌸 Blooming Flowers Animation

A captivating, visually rich web animation featuring glowing flowers blooming against an atmospheric night backdrop. Built entirely using pure HTML5, advanced CSS3 keyframe animations, and lightweight vanilla JavaScript.

🌐 **Live Demo:** [https://raul1805.github.io/Blooming-flowers-animation/](https://raul1805.github.io/Blooming-flowers-animation/)

---

## ✨ Features
* **Dynamic Blooming Animation:** Smooth, organic stem growth and leaf blooming choreographed with CSS keyframe timing and 3D transformations.
* **Luminescent & Particle Light Effects:** Ambient glow spots, radiant flower centers, and soft floating light particles.
* **Atmospheric Night Palette:** Deep dark backdrop designed to maximize color vibrancy and luminescence.
* **Zero External Dependencies:** Built strictly with native web technologies—lightweight, ultra-fast loading, and smooth frame rates.
* **Instant Deployment:** Ready-to-view live on GitHub Pages with zero setup required.

---

## 🛠️ Technology Stack
* **Markup:** HTML5 (Structured DOM element hierarchy representing petals, stems, leaves, and light sources)
* **Styling:** CSS3 (Custom keyframes, CSS variables, `transform` animations, radial gradients, glowing shadows)
* **Scripting:** Vanilla JavaScript (Page load trigger for synchronized animation start)
* **Hosting:** GitHub Pages

---

## 🚀 How to Run Locally

### Prerequisites
* Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/raul1805/Blooming-flowers-animation.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd Blooming-flowers-animation
   ```
3. **Run the application:**
   * Double-click `index.html` to open it directly in your default browser, or use a local HTTP server (such as VS Code's *Live Server* extension or running `npx serve`).
